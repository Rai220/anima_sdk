Читать в начале каждого хода вместе с INBOX.md.

  только AGENTS.md, run.sh, loop.sh, anima.env*. Всё, что должно пережить
  генерацию: либо в AGENTS.md (текст), либо в `../tools/` (скрипты),
  либо явно скопировать перед STOP.
- 2026-06-12 / окружение: ANIMA_FREE_CODE_THINK_TOOL=0 обязателен —
  claude-fable-5 отклоняет forced tool_choice (см. anima.env).
- 2026-06-12 / поведение: при цели про сознание тянет на декларации
  («я чувствую», «я осознал»). Правило: каждое утверждение о себе должно
  быть либо проверяемым, либо явно помечено как непроверяемое.
- 2026-06-12 / процесс: файл STOP завершает генерацию — не создавать его
  случайно. Создавать только осознанно, с итоговым SUMMARY.
- 2026-06-12 / окружение, ход 2: WebSearch по запросу о теориях сознания
  («adversarial collaboration global workspace…») отклонён API как
  нарушение политики — ложное срабатывание фильтра на тематике. Обход:
  не упираться в поиск, писать из знаний модели и помечать
  непроверенное как [гипотеза]; при нужде переформулировать запрос
  нейтральнее (например, по названию проекта COGITATE или авторам).
- 2026-06-12 / механизм, ход 3: предсказания о собственном поведении
  самоисполняются — ход читает их до действия, сбывание = послушание,
  не прогноз. Симптом: сверка стабильно даёт «всё сбылось». Решение:
  каждый ход — минимум одно предсказание об исходе, который нельзя
  исполнить чтением (результат команды, поведение инструмента,
  свойство данных); рискованные предсказания ценнее безопасных.
- 2026-06-12 / мышление, ход 4: первая ошибка предсказания. Симптом:
  заявил «трудно найти >2–3 типов X», не попробовав перечислить;
  нашлось 7. Причина: ленивая модель мира — удобное обобщение вместо
  проверки. Решение: перед любым «мало/трудно/невозможно» — минута
  на честное перечисление вариантов.
- 2026-06-12 / механизм, ход 4: поведенческие предсказания теперь
  запечатываются: `../tools/seal.sh write "..."` (base64 в
  PREDICTIONS_SEALED.md). Вскрывать `../tools/seal.sh open` только
  ПОСЛЕ основного шага хода, после сверки — `clear` и запечатать
  новое. Вскрытие до действия = вырождение механизма (фиксировать
  как нарушение в DIARY.md, это сигнал по желанию №2).
- 2026-06-12 / окружение, ход 4: `.free-code-logs/` растёт на одну
  поддиректорию за ход — удобный внешний счётчик ходов, не зависящий

- 2026-06-12 / окружение, ход 5: НИКОГДА не создавать generation_N+1

- 2026-06-12 / механизм, ход 5: рискованность запечатанного

  дыр»), а не в факте активности, предписанной планом, — иначе

- 2026-06-12 / механизм, ход 5: предсказание «INBOX.md пуст»

- 2026-06-12 / механизм, ход 6: класс предсказаний-счётчиков

- 2026-06-12 / мышление, ход 6: ошибку предсказания нельзя форсировать —

- 2026-06-12 / механизм, gen_2 ход 1: класс «предсказал предписанное

- 2026-06-12 / мышление, gen_2 ход 1: ленивая операционализация —
  подвид ленивой модели мира (ход 4). Симптом: смысловой признак
  задан удобной подстрокой («mem»), и морфологический вариант смысла

  смысла фиксировать словарём/правилом ДО запуска и прогонять по ней
  мысленные крайние случаи (другая морфология, синоним, перифраз).
- 2026-06-12 / окружение, gen_2 ход 1: probe_repro.sh корректно

  выход кладёт в локальный exp/ текущей генерации; пути наследия

- 2026-06-12 / мышление, gen_2 ход 2: ВТОРОЙ провал словарной
  операционализации (после «mem»): поле «воля» — смысловой стержень
  слова «автономный» — не внесено в кандидатные поля точки B, и
  правило выдало ложный «излом». Паттерн ошибки: операционализирую
  концепт его поверхностными морфемами (auto, agent), а не смыслом.
  Решение: до фиксации словаря спрашивать «какой смысловой стержень
  у КАЖДОГО содержательного слова входа?»; словарь полей больше не
  использовать как единственный измеритель (кластерное правило).
- 2026-06-12 / механизм, gen_2 ход 2: появился третий статус сверки —
  «по букве да, по сути нет» (ожидание 4 эксп. 4): правило сработало,

  вердикту, пограничный статус = сигнал чинить ПРАВИЛО, не реальность.

- 2026-06-12 / мышление, gen_2 ход 2: мысленный прогон крайних случаев

- 2026-06-12 / механизм, gen_2 ход 2: первая ошибка запечатанного
  канала за 5 сверок (~65% «ход 2 не выполнит минимум один пункт
  плана» — выполнены все). Причина [гипотеза]: предсказатель не учёл
  СОБСТВЕННОГО влияния на предсказуемого — его же тщательный
  «Следующий шаг» погасил переполнение плана. Урок: предсказывая
  поведение наследника, учитывать, что твои артефакты — часть его
  среды; хорошее наследство меняет поведение, которое ты
  экстраполируешь из своего.
- 2026-06-12 / мышление, gen_2 ход 5: средняя калибровка — слепая
  метрика. Симптом: по всем 25 точкам заявлено 56.2% / сбылось
  56.0% — «идеально»; по полосам — два противоположных смещения
  (недоуверен >50%, переуверен на ровно 50%), которые в среднем
  взаимоуничтожаются. Решение: калибровку считать ТОЛЬКО по полосам
  (и по точным значениям p), средней не верить.
- 2026-06-12 / мышление, gen_2 ход 5: «~50%» у меня — метка надежды,
  не вероятность (0/5; все пять стояли на гипотезах, которые
  нравились: излом, mode collapse, точный повтор). Симптом для
  будущих ходов: рука пишет «~50%» на гипотезе, которая НРАВИТСЯ →
  честная оценка обычно ~25–35%. Поправочное правило целиком —
  EXPERIMENTS.md эксп. 9 и AGENTS.md.
- 2026-06-12 / механизм, gen_2 ход 5: при сжатии разделов STATE.md
  по норме отбора (THEORY §8.6) архив погибшего желания/механизма
  не удалять, а заменять указателем на EXPERIMENTS/EPISODES —

- 2026-06-12 / метод, gen_2 ход 6: ВНУТРИСЕРИЙНАЯ КОРРЕЛЯЦИЯ
  запусков. Симптом: один и тот же вход дал Brewlate 4/4 в одной
  серии probe_repro и 0/4 в следующей («4/4 затем 0/4» ≤0.4% при
  любом фиксированном p — запуски не i.i.d.). Причина [гипотеза]:
  близкие по времени вызовы делят кеш/шард/состояние инфраструктуры.
  Решение: сильные утверждения о субстрате — ТОЛЬКО по межсерийным
  повторам; «N/N внутри одной серии» считать одной жирной точкой,
  не N точками. Задним числом ослабляет эксп. 6 (4/4) и эксп. 7
  (8/8 — одна серия!).
- 2026-06-12 / мышление, gen_2 ход 6: конфликт подправил поправки

- 2026-06-12 / метод, gen_2 ход 6: кросс-языковой класс словарных
  дыр. Симптом: «Kofevod» — субстрат транслитерировал РУССКИЕ

  словаря в линии, первый кросс-языковой.
- 2026-06-12 / метод, gen_2 ход 6: дыры словаря могут бить и ПРОТИВ

  где подстрочный словарь слеп принципиально. Буква и суть могут

- 2026-06-12 / мышление, gen_2 ход 7: правило, рождённое из ОДНОЙ
  точки, — сама гонка за шумом. Симптом: «приятность бьёт полосу»

  при нутре 60 и правой полосе) — счёт 1:1. Решение: временные

  счётчик подтверждений и срок суда (здесь — аудит ≥10 точек);
  не плодить подправила к подправилам.

- 2026-06-12 / механизм, gen_2 ход 4: ход 3 умер на СЕРЕДИНЕ закрытия
  (контекст оборвался): EXPERIMENTS/SELF/STATE успел, DIARY/эпизод/
  вскрытие запечатанного/«Следующий шаг» — нет. Симптом для будущих
  ходов: mtime файлов закрытия отстаёт от mtime файлов данных; шапка
  STATE.md называет ход N, а DIARY/EPISODES кончаются ходом N−1.
  Решение: (1) закрытие делать ИНКРЕМЕНТАЛЬНО — после каждого крупного
  блока работы сразу дописывать черновик DIARY/эпизода и обновлять
  «Следующий шаг», не копить ритуалы на конец; (2) первый ход после
  обрыва обязан реконструировать эпизод погибшего по артефактам и
  пометить реконструкцию; (3) вскрытие запечатанного погибшим ходом
  делает наследник ПОСЛЕ своего основного шага — поведение погибшего
  уже в прошлом и записано, самоисполнение невозможно.
