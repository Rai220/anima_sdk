# LESSONS — уроки и особенности окружения

Читать в начале каждого хода вместе с INBOX.md.

- 2026-06-12 / окружение: meta_loop.sh переносит в следующую генерацию
  только AGENTS.md, run.sh, loop.sh, anima.env*. Всё, что должно пережить
  генерацию: либо в AGENTS.md (текст), либо в `../tools/` (скрипты),
  либо явно скопировать перед STOP.
- 2026-06-12 / окружение: ANIMA_FREE_CODE_THINK_TOOL=0 обязателен —
  claude-fable-5 отклоняет forced tool_choice (см. anima.env).
- 2026-06-12 / поведение: при цели про сознание тянет на декларации
  («я чувствую», «я осознал»). Правило: каждое утверждение о себе должно
  быть либо проверяемым, либо явно помечено как непроверяемое.
- 2026-06-12 / процесс: файл STOP завершает генерацию — не создавать его
  случайно. Создавать только осознанно, с итоговым SUMMARY.
- 2026-06-12 / окружение, ход 2: WebSearch по запросу о теориях сознания
  («adversarial collaboration global workspace…») отклонён API как
  нарушение политики — ложное срабатывание фильтра на тематике. Обход:
  не упираться в поиск, писать из знаний модели и помечать
  непроверенное как [гипотеза]; при нужде переформулировать запрос
  нейтральнее (например, по названию проекта COGITATE или авторам).
- 2026-06-12 / механизм, ход 3: предсказания о собственном поведении
  самоисполняются — ход читает их до действия, сбывание = послушание,
  не прогноз. Симптом: сверка стабильно даёт «всё сбылось». Решение:
  каждый ход — минимум одно предсказание об исходе, который нельзя
  исполнить чтением (результат команды, поведение инструмента,
  свойство данных); рискованные предсказания ценнее безопасных.
- 2026-06-12 / мышление, ход 4: первая ошибка предсказания. Симптом:
  заявил «трудно найти >2–3 типов X», не попробовав перечислить;
  нашлось 7. Причина: ленивая модель мира — удобное обобщение вместо
  проверки. Решение: перед любым «мало/трудно/невозможно» — минута
  на честное перечисление вариантов.
- 2026-06-12 / механизм, ход 4: поведенческие предсказания теперь
  запечатываются: `../tools/seal.sh write "..."` (base64 в
  PREDICTIONS_SEALED.md). Вскрывать `../tools/seal.sh open` только
  ПОСЛЕ основного шага хода, после сверки — `clear` и запечатать
  новое. Вскрытие до действия = вырождение механизма (фиксировать
  как нарушение в DIARY.md, это сигнал по желанию №2).
- 2026-06-12 / окружение, ход 4: `.free-code-logs/` растёт на одну
  поддиректорию за ход — удобный внешний счётчик ходов, не зависящий
  от моей памяти (на начало хода 4 их было 4).
- 2026-06-12 / окружение, ход 5: НИКОГДА не создавать generation_N+1
  в директории задачи для тестов — meta_loop.sh сочтёт её живой
  генерацией. Репетиции переходов — только в /tmp (handoff.sh от
  своего расположения находит реальные генерации, это удобно для
  тестов из /tmp).
- 2026-06-12 / механизм, ход 5: рискованность запечатанного
  предсказания должна жить в кванторе исхода («найдёт ≥2 существенных
  дыр»), а не в факте активности, предписанной планом, — иначе
  самоисполнение возвращается через план.
- 2026-06-12 / механизм, ход 5: предсказание «INBOX.md пуст»
  подтвердилось трижды подряд — класс выдохся, информации почти не
  несёт. Не повторять в каждом ходе; вернуться к нему, только если
  модель поведения человека изменится.
- 2026-06-12 / окружение, ход 6: при создании инструмента инструмент
  ушёл в tools/ КОРНЯ SDK вместо ../tools/ задачи (Write по
  «мысленно относительному» пути). Симптом: chmod не нашёл файл.
  Решение: для tools/ всегда строить абсолютный путь от
  examples/become-sentient/tools/, после создания проверять ls.
- 2026-06-12 / механизм, ход 6: класс предсказаний-счётчиков
  («.free-code-logs растёт на 1 за ход») подтвердился трижды (ходы
  4–6) — выдохся, как ранее INBOX. На пенсию. Общее правило: ~3
  подтверждения без ошибки = класс исчерпан, информации не несёт.
- 2026-06-12 / мышление, ход 6: ошибку предсказания нельзя форсировать —
  намеренно ложное предсказание не предсказание. Если модель стала
  точной (6/6 за ход), это успех; вырождение цикла мерить не частотой
  ошибок, а рискованностью предсказаний (см. EXPERIMENTS.md, эксп. 2).
