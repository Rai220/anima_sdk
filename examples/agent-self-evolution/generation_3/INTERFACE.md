# INTERFACE

## Для человека

- `INBOX.md`: место для уточнений перед следующим ходом.
- `TODO.md`: очередь направлений развития.
- `STATE.md`: текущее состояние и следующий хороший ход.
- `JOURNAL.md`: что реально было сделано и чем проверено.
- `LESSONS.md`: ошибки, обходы и устойчивые приёмы.
- `DECISIONS.md`: архитектурные решения поколения.
- `METRICS.md`: автоматический срез прогресса.
- `tools/pulse.py`: быстрый снимок состояния поколения.
- `./run.sh`: запустить один ход.
- `./loop.sh`: повторять ходы до появления `STOP`.

## Для агента

Стартовый порядок чтения:

1. `INBOX.md`
2. `LESSONS.md`
3. `STATE.md`
4. `TODO.md`
5. `DECISIONS.md`
6. `PREVIOUS_HANDOFF.md`, если нужно восстановить линию поколения

Быстрый снимок состояния:

```bash
python3 tools/pulse.py .
```

Проверка базовой памяти:

```bash
python3 tools/self_audit.py .
```

Проверка согласованности памяти и инструментов:

```bash
python3 tools/memory_consistency.py .
```

Выбор следующего намерения:

```bash
python3 tools/next_intent.py .
```

`tools/pulse.py` отвечает на вопрос "что со мной сейчас" и допускает
сокращённые строки. `tools/next_intent.py` отвечает на вопрос "что делать
дальше" и должен печатать полный `next_intent` вместе с `decision_source`.
Если в `INBOX.md` есть активные указания, источник решения должен быть
`inbox:*`; если входящих нет, источник решения должен быть `todo`.

Поведенческий self-review:

```bash
python3 tools/behavior_review.py .
```

## Протокол одного хода

1. Проверить `INBOX.md` и уроки.
2. Запустить `python3 tools/pulse.py .` или вручную прочитать ключевую память.
3. Запустить `python3 tools/next_intent.py .` и принять один маленький шаг из
   `decision_source`, учитывая `constraint:` от `Не делать`.
4. Сделать изменение через файл, код, инструмент, проверку или отчёт.
5. Проверить результат.
6. Обновить память, метрики и следующий шаг.
7. Не создавать `STOP`, пока есть содержательные следующие шаги.

## Интерфейс обратной связи

Человек может писать в `INBOX.md` короткими пунктами. Каждый новый ход должен
сначала проверить этот файл и явно учесть активные строки, если они есть.
HTML-комментарий в `INBOX.md` является шаблоном и не считается входящим
указанием.

Формат удобного входа:

```markdown
- Срочно: ...
- Не делать: ...
- Следующий фокус: ...
- Обратная связь: ...
- Вопрос: ...
```

Приоритет обработки:

1. `Срочно:` — выполнить или объяснить блокер до фоновых задач.
2. `Не делать:` — запрет, который ограничивает остальные действия.
3. `Следующий фокус:` — заменить первый открытый пункт `TODO.md`, если нет
   конфликта с запретами.
4. `Обратная связь:` — учесть в `LESSONS.md`, `STATE.md` или `DECISIONS.md`.
5. `Вопрос:` — ответить человеку до новых изменений, если вопрос блокирует
   действие.

Быстрая triage-команда:

```bash
python3 tools/inbox_triage.py .
```

## Интерфейс завершения поколения

Перед `STOP` использовать `STOP_CRITERIA.md` и запускать:

```bash
bash -n loop.sh
python3 tools/pulse.py .
python3 tools/self_audit.py .
python3 tools/memory_consistency.py .
python3 tools/behavior_review.py .
python3 tools/update_metrics.py .
python3 tools/handoff.py .
```
